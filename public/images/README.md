# Images Directory

This directory contains images used throughout the portfolio website.

## Required Images

### Profile Photo
- **Path**: `/public/images/chau-photo.jpg`
- **Description**: Your profile photo displayed in the About section
- **Recommended size**: 300x300px or larger (square aspect ratio)
- **Format**: JPG, PNG, or WebP

### Reading Images
- **Path**: `/public/images/readings/`
- **Description**: Book cover images or reading-related images for the carousel
- **Recommended size**: Max width 600px
- **Format**: JPG, PNG, or WebP
- **Naming**: Use descriptive names (e.g., `book-title.jpg`)

## Usage

Update the image paths in the data files:
- Profile photo: `/src/data/about.ts`
- Reading images: `/src/data/readings.ts`

## Optimization Tips

1. Compress images before uploading
2. Use WebP format for better performance when possible
3. Provide descriptive alt text for accessibility
4. Consider using retina (@2x) versions for high-resolution displays
